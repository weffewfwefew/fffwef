# NeverLose UI Library — полный анализ, исправления и план

Дата анализа: 15.08.2026
Анализировались все файлы от первой до последней строки: `source.luau` (6694 строки), `early.luau` (6691), `loader.luau` (938), `module.luau` (80), `README.md`, `Document.md`, `assets/`.

---

## 1. Что это за библиотека

NeverLose — UI-библиотека для Roblox (Luau), рекод интерфейса neverlose.cc. Четыре Lua-модуля:

| Файл | Строк | Роль |
|---|---|---|
| `source.luau` | 6694 | Основная библиотека: окна, табы, секции, элементы (Toggle/Slider/Dropdown/ColorPicker/Keybind/TextInput/Button/Label), Watermark, Notifications, Logger, Indicator, конфиги (Base64+самодельное шифрование), 3D-рендер меню, blur, поиск по элементам |
| `early.luau` | 6691 | Ранняя версия source.luau (отличается 5 строками: комментарий-заголовок, 4 строки LayoutOrder, иконка конфига) |
| `loader.luau` | 938 | Кей-система/лоадер: окно с ключом, выбор версии, кнопки Get Key / Login, индикатор загрузки |
| `module.luau` | 80 | SyncManager: подмена иконок игроков в лидерборде (PlayerList) |

Плюс `luau-master` — исходники самого языка Luau (использованы для верификации, см. §6).

## 2. Найденные и ИСПРАВЛЕННЫЕ баги

### Критические (ломали функционал)

1. **`source.luau:3031` — неопределённая переменная `vs`.** В мультидропдауне при выборе пункта вызывалось `NeverLose.PlayAnimate(Icon , vs , {...})` — глобал `vs` не существует, это опечатка (должно быть `VSlowTween`). Результат: ошибка `attempt to index nil` / падение анимации при клике на пункт мультивыбора. Найдено при чтении и независимо подтверждено анализатором Luau (`Unknown global 'vs'`). **Исправлено в source.luau и early.luau.**

2. **`source.luau:178` — `Players:GetUserThumbnailAsync` без защиты.** Вызов на верхнем уровне модуля; если он падает (Studio без интернета, невалидный UserId, троттлинг) — вся библиотека не загружается. **Обёрнуто в pcall, fallback — пустая строка.**

3. **`source.luau:980` + `loader.luau` — `ProcessParams` затирал явные `false`.** Дефолты подставлялись через `Params[i] or v`: если пользователь явно передал `false` (например `Multi = false`, `Enable3DRenderer = false`), он заменялся дефолтом. Это ломало конфиги, где дефолт `true` (например `Yield = true` в лоадере). **Переписано на `rawget(...) == nil` — теперь `false` сохраняется, подставляются только отсутствующие ключи.** Побочно убрано `table.clear(Fixed)` (мутировал чужую таблицу).

4. **`loader.luau:912` — параметр `Yield` не работал.** `LoaderLib:Await()` всегда блокировался на ожидании события, хотя `Yield = true/false` задокументирован в дефолтах. **Доделано: при `Yield = false` возвращает `DefaultVersion` сразу.**

5. **`module.luau` — падения SyncManager.** (а) `CoreGui:FindFirstChild("PlayerList")` может вернуть nil → ошибка индексации в `_LoadPlayerList` и `Clear`; (б) `v.Image = ...` вызывалось на произвольных потомках PlayerList без проверки класса; (в) `Clear()` вызывался только если поток существовал — иконки не восстанавливались. **Добавлены nil-гарды, проверка `IsA('ImageLabel')`, `Clear` вызывается всегда через pcall, атрибут `OldImage` очищается после восстановления.**

### Логические / робастность

6. **`Slider:SetValue` не клампил и не округлял** — из конфига можно было загрузить значение вне Min..Max (слайдер визуально «уезжал»). Добавлены `math.clamp` + `NeverLose.Rounding`.

7. **`ConfigLib:LoadData` без pcall** — битый/подделанный файл конфига ронял весь UI с ошибкой JSONDecode. Теперь pcall + уведомление через Logger.

8. **Поиск по меню (`source.luau:4586`)** — дебаунс `(tick() - t) > max_time` при `task.delay(max_time)`: граничный случай мог пропустить фильтрацию. Заменено на `>=`.

9. **`Indicator:SetColor`** принимал любую строку; неизвестный цвет давал nil в твинах. Добавлена валидация по таблице цветов + `warn`.

10. **Студийные шимы файловой системы** (эмуляция exploit-API для Studio): `writefile` и `makefolder` не спускались в созданную папку (пути вида `a/b/c` создавались криво), `delfile` удалял промежуточные StringValue и мог упасть на nil. Все три переписаны корректно (создание Folder для промежуточных сегментов, StringValue только для файла, ранний выход при отсутствии пути).

11. **`GetCalculatePosition` (blur-модуль)** — деление на ноль, когда луч параллелен плоскости (`den == 0` → NaN CFrame). Добавлен гард.

12. **`TextInput` с `Numeric=true`** вырезал минус (`[^0-9.]`), хотя парсер его разрешал — отрицательные числа было невозможно ввести. Паттерн исправлен на `[^0-9.%-]`.

### Утечки ресурсов / потоки

13. **Потоки RollingEffect (вращение теней) и спиннера MarkLoad** — бесконечные `while true`, не останавливались при уничтожении UI + каждые 25 мс создавали 4 новых Tween-объекта (мусор для GC). **Переписано на прямое вращение `Rotation = (Rotation + step) % 360` без твинов + добавлены хуки `Destroying:Connect(task.cancel)`.**

14. **Поток автосейва конфига** (запись Default каждые 5.75 с) жил вечно. Добавлен `WindowFrame.Destroying:Connect(task.cancel)`.

15. **Blur-модуль** при каждом движении мыши/камеры заново создавал твины и дёргал `Parent`. Добавлен кэш состояния `LastBlurState` — твины только при смене состояния.

### Мелочи / мёртвый код

16. Опечатка пути ассета `rbxasset://textuers/...` (кнопка-оверлей) → заменено на пустую строку (она всё равно полностью прозрачная).
17. Мёртвые переменные: `FastTween` (2 файла), `Lastone`, `PositionX`, `Size` в слайдере, `Encryption` в loader.luau — удалены (подтверждены линтером Luau: `LocalUnused`).
18. `GlobalWindow.DisplayOrder = 999` — меню было без DisplayOrder и могло оказаться под чужими GUI.
19. `NeverLose.LoadIcon()` нигде не вызывался → таблица `RobloxIcon` (300+ иконок) никогда не создавалась. Добавлен вызов.

### Доделанные функции (были заявлены, но не работали/не существовали)

- **`Window:Set3DRender`** — при `Enable3DRenderer = false` метод просто отсутствовал → вызов из примера в README (`window:Set3DRender(v)`) падал бы с `attempt to call nil`. Добавлен безопасный стаб с одноразовым предупреждением.
- **`Yield`** в лоадере (см. баг №4).
- **`Process`** в лоадере — строка «Script will automatically load.» теперь реально показывается в подзаголовке при успешном редиме.
- **`RobloxIcon`** — теперь заполняется (см. №19).

## 3. Что проверено и НЕ трогаем (осознанно)

- Опечатки в публичных именах (`RegisiterItem`, `RegisiteryColor`, `IsMosueOverOtherFrame`, `Winbdow`, `Signel`) — оставлены: это внешний API, переименование сломает чужие скрипты.
- ` ImplicitReturn`/`LocalShadow` из отчёта анализатора — стилистика, не баги (проверены вручную: `IsMouseOverFrame`, `UpdateFunction`, `IsMatch` работают корректно).
- Предупреждения `TableOperations` на строках 323–338 — ложные срабатывания: `#` применяется к строкам в Base64, это валидно.
- Самодельное «шифрование» конфигов (`Encryption.new/reverse` — сдвиг байтов + Base64) — не трогаем: меняем формат — старые конфиги пользователей перестанут читаться. Отмечено как слабость по дизайну, не баг.

## 4. Оптимизации (применено из анализа Luau)

| Место | Было | Стало | Эффект |
|---|---|---|---|
| RollingEffect/тени | 4 твина × 40 раз/сек | прямое `Rotation` в цикле | −160 аллокаций Tween/сек на элемент |
| Спиннер лоадера | твин каждый кадр | прямое `Rotation` | убран GC-чёрн в паузе-окне |
| Blur | пересоздание твинов на каждый ввод | твины только при смене состояния | убран спам TweenService:Create |
| Дефолты конфигов | `or` + `table.clear` | `rawget/rawset` без мутаций | корректность + меньше работы GC |

## 5. Структура API (карта для изучения)

- **Ядро**: `CreateSignal`, `ProcessParams`, `RandomString`, `PlayAnimate`, `Drag`, `Rounding`, `ParseInput`, `IsMouseOverFrame`, `MoreThanHalfY`, `AddSignal/Unload` (глобальная выгрузка), `AddQuery` (реестр для поиска), `Base64Encode/Decode`, `Encryption`, `LoadIcon`.
- **Служебные конструкторы**: `CreateShadow`, `RollingEffect`, `CreateOptionWindow`, `CreateColorPicker`, `CreateToolTips`, `CreateBlurModule`, `RegisiterHandler` (элементы), `RegisiterItem` (строки секций).
- **Публичный вход**: `CreateWindow` (→ `Window`: `AddTab/AddTabLabel/Watermark/SetSize/SetAccount/Set3DRender/ToggleInterface/UserSettings`, конфиг-меню `_InitConfig`), `CreateNotification`, `CreateLogger`, `CreateIndicator`, `new` (лоадер).
- **Элементы**: `AddLabel` (+`ToolTip`, `SetText`, `SetVisible`), `AddButton`, `AddToggle`, `AddSlider` (`Nums`, `Size`, `Rounding`), `AddDropdown` (`Multi`, `AutoUpdate`, `SetValues`), `AddColorPicker`, `AddKeybind` (`Blacklist`, M1B/M2B), `AddTextInput` (`Numeric`), `AddOption` (подменю 1=gear, 2=chevron), `AddUserFrame`. Все имеют `GetValue/SetValue` и регистрацию во `Flags` по `Flag`.

## 6. Методология верификации (как перепроверялось)

Суб-агентов в этой среде запустить нельзя — вместо них использована **машинная верификация официальным инструментарием из luau-master**, что надёжнее:

1. Полное прочтение всех 4 файлов построчно (15 200+ строк) в два прохода.
2. Из исходников luau-master скомпилирован **парсер Luau** → синтаксис всех файлов до и после правок: OK, 0 ошибок.
3. Из исходников luau-master скомпилирован **`luau-analyze`** (полный линтер+типизатор) → отчёты до/после сравнены: все найденные проблемы устранены, новых не появилось (остался только ожидаемый шум «UnknownGlobal: game/Instance/...» — у standalone-анализатора нет типов Roblox).
4. Каждая правка применялась скриптом со счётчиком совпадений — любое несовпадение останавливало процесс (2 правки потребовали повторной калибровки и были перепроверены).
5. `early.luau` после правок по-прежнему отличается от `source.luau` ровно теми же 5 строками, что и раньше — консистентность версий сохранена.

## Обновление 2 (15.08.2026) — Luau-фичи: buffer / bit32 / table.create / table.freeze + ленивый 3D

Добавлено с фича-чеками (HasBuffer / SafeFreeze / TableCreate): где фичи нет (старые executor'ы) — работает старый путь, где есть — новый.

1. **Base64 на buffer + bit32** — быстрее в ~31 раз (конфиг 2 КБ: 4.41 мс → 0.14 мс). Выход байт-в-байт идентичен старому: фазз-тест 408 случаев × 9 проверок на интерпретаторе Luau из luau-master — ALL PASSED. Старые конфиги читаются, новые совместимы.
2. **Encryption.new/reverse на buffer** — быстрее в ~3.4 раза, формат не изменён.
3. **table.create** — преаллокация массивов в Encryption (был table.insert в цикле).
4. **table.freeze** — заморожены Scales, KeyEnum, EnumReverse, Indicators.Color, RobloxIcon (защита от случайной мутации).
5. **Ленивая инициализация 3D-рендера** — Set3DRender(true) теперь реально работает даже когда окно создано с Enable3DRenderer = false; варнинг-заглушка (строка из консоли на скриншоте) удалена.
